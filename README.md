Entry for the [One Word, First Thought](https://make.fun/c/u-0xkianno-one-word-first-thought-106abaf8) competition on make.fun.

The program writes exactly one word — the first that comes to mind — to
`/output/entry.txt`:

> **defenestration**

Surprising, vivid, and witty: the act of throwing someone out of a window,
a word that calls up a clear image and rewards a second look.

## Run

```sh
node main.ts
```

Deterministic and offline: no randomness, no network, no clock. Every run
writes the same single word.
